Download the free game from [Adventure Game Studio](https://www.adventuregamestudio.co.uk/play/game/1737)

## 1. Bedroom

- USE door
- USE intercom
- PICK UP towel (`Towel`)
- PICK UP wakizashi (from the desk) (`Wakizashi`)
- USE `Wakizashi` on panel (under the poster)
- USE `Towel` on pipes (`Wet Towel`)
- USE `Wet Towel` on Dai (yourself)
- USE broken chair (`Chair Leg`)
- USE `Chair Leg` on intercom
- USE `Chair Leg` on window controls
- PICK UP gloves (from the bed) (`VR Gloves`)
- USE `VR Gloves` on the window controls
- USE `VR Gloves` on intercom
- USE Dai
- USE window

## 2. Street

- TALK TO truck driver **2 times**

>Nell

- TALK TO heavy guy
  - If you switch characters (second option), change back to Nell, the woman
- TALK TO truck driver
- SWITCH to Dai (TALK TO him and select the second option)

>Dai

- USE truck engine
  - LOOK AT radiator cap
  - USE `Wet Towel` on radiator cap

>Nell

- USE engine
  - USE `Water Bottle` on ???? (the radiator)
