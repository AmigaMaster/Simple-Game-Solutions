# Heed - Walkthrough

| Version | Date       | Author
|:-------:|------------|-------------------------------------------
|   1.0   | 02.07.2026 | Amiga Master (AmigaMaster-NG@t-online.de)

Download the free game from [archive.org](https://archive.org/details/heed-2009)

## 1. Pillar

- USE fly **7 times** (until you talk to the ghost)
- USE fly (`Fly`)
- USE pillar
  - "Examine..."
  - "Place fly..."

## 2. Tree

- USE tree
  - "Examine..."
  - "Touch..."
- USE spirit
  - "Greet..."
  - "Examine..."
  - "Touch..."
- USE tree
  - "Touch..." (Turn lights off)
- USE fly (it flies up to the spirit)
- USE tree
  - "Touch..." (Turn lights on)
- USE fly (it flies onto the spirit)
  - Do you know anything about..."

## 3. Bridge

- WALK east
- USE statue
  - "Examine..."
  - "Talk..."
  - "Touch..."
- WALK east (you have a conversation and automatically EXIT east)

## 4. House

- USE door **2 times** (you will exit east)

## 5. Ruins

- USE rubble
- USE statue
- USE tree
- TALK TO Spirit

## 6. Top of Rock

- USE pillar
- TALK TO Spirit

## 7. Statues

- USE (right) statue (place)
- USE (middle) statue (of)
- USE (left) statue (knowledge)
- USE (right) statue (lies)
- USE (left) statue (past)
- USE (middle) statue (here)
- USE (left) statue (seek)
- USE (right) statue (hollow)
- USE (middle) statue (passage)

## 8. Underground Entrance

- USE lights (numbered from left to right) `4, 3, 1, 2`

### 8.1. Spheres

- USE (right) light
- USE (rightmost) light
- USE light (above the door)
  - **NOTE**: `3, 1, 4, 2`
- Return to the left side to the smaller lights
- USE (smaller) light (numbered from left to right) `2, 3, 1, 4`

## 9. Ruins

- USE statue
