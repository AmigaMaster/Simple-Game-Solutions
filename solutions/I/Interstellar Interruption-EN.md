## 1. Your Room

- PICK UP device (`Device`)
- USE `Device`
  - If you want, read the data
  - "Settings"
  - "Battery"
  - "Yes"
  - USE slot (at the bottom of the device)
  - PICK UP battery from the slot (`Battery`)
- USE computer
  - **NOTE:** the meeting room door function `110100111001`
  - **NOTE:** the DMG 442 codes:
    - Reboot `daydream moon alligator`
    - Shutdown `photograph honey regular`
    - Override `band spider mars`
- EXIT north

## 2. Corridor

- USE door
  - USE `Battery` in slot
  - ENTER meeting room door function `110100111001`
- EXIT north

## 3. Meeting Room

- USE **both** dead bodies (`Audio Log`)
- TALK TO robot
  - ENTER reboot code `daydream moon alligator`
  - ENTER override code `band spider mars`
  - **NOTE:** Coordinates `Alpha 392`, `Kappa 118`, `Delta 040`
- EXIT north west

## 4. Bridge

- USE dead body (`Audio Log`)
- USE computer
  - ENTER codes from the robot `Alpha 392`, `Kappa 118`, `Delta 040`
