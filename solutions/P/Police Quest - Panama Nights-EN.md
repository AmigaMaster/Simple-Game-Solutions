# Police Quest: Panama Nights - Walkthrough

Download the free game from [Itch.io](https://brushfe.itch.io/police-quest-panama-nights)

## 1. Street

### 1.1. Bar Callejo

#### 1.1.1. Sonny's Room

- PICK UP beer bottle (in front of the bed) (`Beer Bottle`)
- USE bed cushion
- PICK UP pistol (`Pistol`)
- USE bed cushion
- OPEN desk drawer
- PICK UP passport (from the drawer) (`Passport`)
- EXIT south (USE door)

#### 1.1.2. Hallway

- TALK TO kid
- USE `Passport` on bottom right door
- EXIT downstairs

#### 1.1.3. Back Room

- USE bottom left box (`Lime`)
- EXIT north

#### 1.1.4. Bar

- TALK TO bartender (Xavier) (`Wallet`)
- TALK TO people on the lower left table
- TALK TO man in the white suit on the right table
- TALK TO woman
- **ATTENTION:** SAVE YOUR GAME HERE
- USE south door to exit

## 2. Street

- **QUICK:**
  - USE `Passport` or `Wallet` on soldier
- TALK TO drunk
- TALK TO sex worker **2 times**
- USE drunk
- USE `Beer Bottle` on drunk (`Shoe`)
- USE `Shoe` (`Stiletto Heel`)
- ENTER bar

### 2.1. Bar Callejo

#### 2.1.1. Bar

- EXIT north

## 3. Back Room

- USE right door
- PICK UP bottle in the bottom right (`Air Freshener`)
- EXIT south

### 3.1. Alley

- USE `Stiletto Heel` on right door
- **ATTENTION:** SAVE YOUR GAME HERE
- USE right door

#### 3.1.1. Storage Room

- **QUICK:**
  - USE the upper right barrel to climb it up
  - PICK UP six pack (`Six Pack`)
  - USE barrels to climb down
  - USE upper left barrel to climb up
  - PICK UP towel (`Towel`)
  - USE barrel to climb down
  - WALK to door
  - USE `Stiletto Heel` on door
  - USE door

### 3.2. Alley

- USE left door

### 3.3. Bar Callejo

#### 3.3.1. Bar

- TALK TO drunk
- **ATTENTION:** SAVE YOUR GAME HERE
- USE drunk
- **QUICK:**
  - USE `Air Freshener` on the drunk
  - USE `Six pack` on drunk

## 4. Street

- USE drunk (`Lighter`, `Cigarettes`)
- TALK TO taxi driver
- USE `Wallet` on taxi driver
- USE `Pistol` on taxi driver
