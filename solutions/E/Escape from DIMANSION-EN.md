# Escape from DIMANSION - Walkthrough

| Version | Date       | Author                                    |
|:-------:|------------|-------------------------------------------|
|   1.0   | 09.08.2026 | Amiga Master (AmigaMaster-NG@t-online.de) |

Get free game from [itch.io](https://shdon.itch.io/dimansion)

## 1. Library

- PICK UP creepy book (`Words`, `Broken Block`)
- PICK UP strange brick (on the floor under the left bookshelf) (`Up-or-Down Block`)
- PICK UP pincers (`Pincers`)
- USE `Up-or-Down Block` with indentation (on the left side of the miniature house)
- EXIT west

## 2. Art Gallery

- PICK UP block (`Flame Block`)
- PULL easel
- EXIT east

## 3. Library

- TURN up-or-down block
- EXIT west

## 4. Upside-Down Art Gallery

- PICK UP block (`Chasm Block`)
- OPEN hatch
- EXIT east

## 5. Library

- USE `Flame Block` with (right) indentation
- EXIT east

## 6. Fireplace Room

- PICK UP nice with small figurine (`Toy Figure`)
- PICK UP fireplace (`Ashes`)
- EXIT west

## 7. Library

- USE `Chasm Block` with flame block (`Flame Block`)
- EXIT east

## 8. Chasm

- PICK UP block (`Safe Block`)
- EXIT west

## 9. Library

- USE `Safe Block` with chasm block (`Chasm Block`)
- EXIT east

## 10. Right Safe Room

- USE `Pincers` on stuck fly
- PICK UP dead fly
- USE `Ashes` with wall
- LOOK AT sooty numbers (`Code`)
- TURN `Code` (`Code` (Turned))
- USE `Code` (Turned) with safe
- EXIT west

## 11. Library

- PICK UP safe block (`Safe Block`)
- USE `Safe Block` with up-or-down block (`Up-or-Down Block`)
- EXIT west

## 12. Left Safe Room

- USE `Code` with safe
- OPEN safe (`Broken Block` (Second))
- EXIT east

## 13. Library

- USE `Broken Block` (the first one) with (right) indentation
- EXIT east

## 14. Broken Room

- PICK UP protruding brick (`Block of Growth`)
- USE `Pincers` with floating magnet (`Magnet`)
- EXIT west

## 15. Library

- PICK UP broken block `Broken Block`
- USE `Broken Block` with `Broken Block` (`Exit Block`)
- USE `Block of Growth` with indentation
- USE `Toy figure` with block of growth
- USE `Speck of Glitter` with block of growth
- EXIT east

## 16. Lego Room

- PICK UP huge magnifier (`Magnifier`)
- PICK UP shiny flake (`Shiny Flake`)
- EXIT west

## 17. Library

- USE `Shiny Flake` on block of growth
- EXIT east

## 18. Lego Room

- PICK UP mirror (`Mirror`)

## 19. Library

- USE `Up-or-Down Block` with safe block (`Safe Block`)
- TURN up-or-down block
- EXIT west

## 20. Art Gallery

- USE `Mirror`  with easel
- EXIT east

## 21. Library

- USE `Chasm Block` with block of growth (`Block of Growth`)
- USE `Magnet` with chasm block

## 22. Chasm

- OPEN rusty metal chest (`Cold Block`, `Flashlight`)
- EXIT west

## 23. Library

- USE `Flame Block` on chasm block (`Chasm Block`)
- EXIT east

## 24. Fireplace Room

- USE `Magnifier` with base
- EXIT west

## 25. Library

- USE `Flashlight` with up-or-down-block
- EXIT east

## 26. Fireplace Room

- USE `Cold Block` with fireplace
- USE `Pincers` with fireplace (`Cold Block` (Heated))

## 27. Library

- USE `Cold BLock` (Heated) with up-or-down block (`Up-or-Down Block`)
- EXIT west

## 28. Cold Room

- PICK UP key (`Brass Key`)
- EXIT east

## 29. Library

- USE `Exit Block` with flame block (`Flame Block`)
- EXIT east

## 30. Hallway

- USE `Brass Key` with ornate door
