# Eternally Us - Walkthrough

| Version | Date       | Author                                    |
|:-------:|------------|-------------------------------------------|
|   1.0   | 05.09.2022 | Amiga Master                              |

Get the free game from [Archive.org](https://archive.org/details/eternally-us)

## 1. Park

- USE lamp post
- USE trash can
- USE lamp post
- USE bush
- USE path
- USE bush
- USE path

## 2. Rooftop

- USE crate
- USE metal pipe on crate **2 times**
- USE crate
- USE door

## 3. Swamp

- WAIT some seconds
- USE tree root **3 times**  
  **NOTE:** You need to catch the root, then wait until it stops moving and then click again
- USE other tree root **3 times**

## 4. Entrance to Cemetery

- USE plaque
- USE a small glow (`Glow Worm`) **3 times**
- USE `Glow Worm` on statue
- USE `Glow Worm` on lamp **on both lamps**
- USE glimmering light (`Key`)
- USE `Key` on chest
- USE chest (`Stone Heart`)
- USE `Stone Heart` on statue

## 5. Forest

- USE berry bush (`Berries`)
- Walk to the bucket
  - USE `Berries` on squirrel
- Walk to the right tree
  - USE `Berries` on squirrel
- Walk to the bucket
  - USE `Berries` on squirrel
- USE acorn (`Acorn`)
- USE rock (`Rock`) **3 times**
- USE `Rock` on bucket **3 times**
- USE bucket (`Bucket`)
- USE `Bucket` on well (`Water-Filled Bucket`)
- USE `Water-Filled Bucket` on acorn (`Acorn`)
