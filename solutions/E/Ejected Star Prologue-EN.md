# Ejected Star Prologue - Walkthrough

| Version | Date       | Author                                    |
|:-------:|------------|-------------------------------------------|
|   1.0   | 02.11.2022 | Amiga Master (AmigaMaster-NG@t-online.de) |

Download the free game from the [Itch.io](https://ejected-star.itch.io)

## 1. Your Quarter

- PICK UP ID card from the floor (`ID-card`)
- EXIT south

## 2. Turbolift

- USE `ID-card` with elevator controls
- EXIT south

## 3. Deck 17

### 3.1. Elevator Hallway

- EXIT west

### 3.2. Left Hallway

- ENTER door
- USE dark shapes (`Mop`)
- EXIT west

### 3.3. Left Incomplete Room

- USE `Mop` with brick and key (`Brick and Key`)

### 3.4. Elevator Hallway

- EXIT east

### 3.5. Right Hallway Junction

- USE crack
- EXIT northeast

### 3.6. Northeast Hallway

- EXIT east

### 3.7. Hallway with Crates

- USE `Brick and Key` with door
- USE door

#### 3.7.1. Workshop

- PICK UP screwdriver (`Screwdriver`)
- LOOK AT interesting note
- PICK UP tape (`Roll on Tape`)

### 3.8. Elevator Hallway

- LOOK AT notes (`Combo Scrap`)

### 3.9. Left Hallway

- LOOK AT all three lockers
- USE `Combo Scrap` with Maint. locker
- PICK UP pink canister (`Hull Sealant`)
- PICK UP wire cutters (`Wire Cutters`)
- LOOK AT scrap of paper

### 3.10. Right Hallway Junction

- USE `Hull Sealant` with crack

## 4. Your Quarter

- USE console

## 5. Deck 17

### 5.1. Right Hallway Junction

- EXIT southeast

### 5.2. Reactor

- USE `ID-card` with door controls
- USE `Wire Cutters` with wire (`Wire`)

### 5.3. Elevator Hallway

- USE `Roll on Tape` with screen (`Tape With Fingerprint`)

### 5.4. Hallway with Crates

#### 5.4.1. Workshop

- USE `IS-card` with drafting board
- USE `Tape with Fingerprint` with drafting board
  - "Yes"
  - "Engineer"
  - "Deck 17"
  - "Engines"
  - "349"

### 5.5. Reactor

- USE `ID-card` with door controls
- USE airlock controls
- LOOK AT bomb **2 times**

## 6. Your Quarter

- USE books (`Crude Bomb Manual`)

## 7. Deck 17

### 7.1. Reactor

- USE `Crude Bomb Manual` with bomb
- USE bomb manual
- USE `Wire Cutters` with bomb
- USE bomb manual
- USE `Wire Cutters` with bomb
- USE bomb manual

### 7.2. Northeast Hallway

- USE `Screwdriver` with middle door controls
- USE `Wire` with door controls
- USE door controls
- PICK UP wire kit (`Wire Kit`)

### 7.3. Reactor

- USE `Wire Kit` with bomb
- Leave the reactor

### 7.4. Left Incomplete Room

- Walk to

### 7.5. Northeast Hallway

- ENTER middle door
  - "No time to stick..."

#### 7.5.1. Escape Pod

- USE control panel
- USE `Mop` with control panel
- USE floor **3 times**
- PICK UP pen (`Pen`)
- USE `Wire Kit` with `Mop` (`Mop with Wire`)
- USE `Mop with Wire` with (`Pen`) (`PenMop`)
- USE `PenMop` with control panel **3 times**
