# Beyond Reality - Walkthrough

| Version | Date       | Author                                    |
|:-------:|------------|-------------------------------------------|
|   1.0   | 13.01.2026 | Amiga Master (AmigaMaster-NG@t-online.de) |

Download the free game from [archive.org](https://archive.org/details/beyond-reality)

## 1. First Floor

### 1.1. Entrance Hall

- PICK UP empty pill bottle (`Empty Pill Bottle`)
- EXIT west

### 1.2. Kitchen

- PICK UP note (`Note`)
- LOOK AT `Note`
- PICK UP hook (`Hook`)
- EXIT east

### 1.3. Entrance Hall

- EXIT east

## 2. Second Floor

### 2.1. Hallway

- PICK UP fishing rod (`Fishing Rod`)
- USE `Hook` with `Fishing Rod` (`Rod and Hook`)
- USE `Rod and Hook` with attic door

## 3. Attic

- PICK UP sleeping pills (`Sleeping Pills`)
- WALK TO window

### 3.1. Roof

- USE `Sleeping Pills` with large drop (on the right)

## 4. Dream World

### 4.1. Cliff

#### 4.1.1. Flying Rock

- LOOK AT distant star
- EXIT upstairs

#### 4.1.2. Cliff

- EXIT northeast

#### 4.1.3. Small Village

- You are standing on the left side of the screen
- CLICK on the path left from the grey building to get to this point then walk right and
- ENTER toy shop

##### 4.1.3.1. Toy Shop

- TALK TO toyshop owner (`Large Toy Snake`)
- EXIT shop

#### 4.1.4. Small Village

- WALK southeast to the house
- ENTER house

##### 4.1.4.1. House

- PICK UP chili powder (`Chili Paste`)
- PICK UP laxative pills (on the table below the right cup) (`Laxative Pills`)
- EXIT house

#### 4.1.5. Small Village

- WALK TO kids corner

##### 4.1.5.1. Kids Corner

- USE `Chili Paste` with red paint (`Poster Paint`)
- USE `Poster Paint` with `Large Toy Snake` (`Large Stuffed toy Snake`)
- EXIT east

#### 4.1.6. Small Village

- EXIT north

#### 4.1.7. Mountain

- USE `Laxative pills` with giant bird
- USE `Large Stuffed toy Snake` with giant bird
- EXIT southwest

#### 4.1.8. Small Village

- WALK TO cliff edge (the red painting on the cliff) (`Rope`)
- EXIT northeast

### 4.2. Map

- ENTER village in the northeast

### 4.3. Village

#### 4.3.1. Street

- ENTER shoe shop

##### 4.3.1.1. Shoe Shop

- TALK TO shoe saleswoman (`Insoles`)
- LOOK AT `Insoles`
- EXIT west

#### 4.3.2. Street

- USE `Insoles` with led melter (`Lead-Coated Insoles`)
- PICK UP (pink) pillow case (`Pillow Case`)
- EXIT north

#### 4.3.3. Outside Tent

- EXIT west

#### 4.3.4. Forest

- LOOK AT flowers (`Larvae`)
- EXIT west

#### 4.3.5. Outside Tent

- ENTER tent

##### 4.3.5.1. Tent

- TALK TO inconspicuous old man
- USE `Larvae` with red leather sack
- USE `Lead-Coated Insoles` with shoes (below the blue sack)
- TALK TO inconspicuous old man
  - "I'm ready." (`Money`)
- EXIT east **2 times**

#### 4.3.6. Street

- ENTER pub

##### 4.3.6.1. Pub

- TALK TO barwoman (`Barrel of Alcohol`)
- TALK TO drunk
- USE `Barrel of Alcohol` with drunk (`String`, `Tickly Feather`, `Paper`)

#### 4.3.7. Forest

- EXIT west, east **2 times**

### 4.4. Map

- WALK TO volcano

### 4.5. Volcano

#### 4.5.1. Outside Volcano

- TALK TO guard
- EXIT north

#### 4.5.2. Ledge

- USE `Tickly Feather` with `Rope` (`Tickly Rope`)
- USE `Tickly Rope` with ridiculous drop

#### 4.5.3. Volcano Cave

##### 4.5.3.1. Entrance

- EXIT east

##### 4.5.3.2. Staircases

- LOOK AT `Paper`
  - **NOTE:** `UP, DOWN, RIGHT, LEFT`
- FOLLOW the path from the `Paper`

### 4.6. Lair

#### 4.6.1. Hallway

- EXIT north

#### 4.6.2. Scenery

- ENTER tree
- ENTER door to the tree

#### 4.6.3. Control Room

- **ATTENTION:** SAVE YOUR GAME HERE because of a game breaking bug
- PICK UP petrol (`Petrol`)
  - **ATTENTION:** Do not use the `String` with the `Petrol`. You won't be able to use it with the `Fire Extinguisher` and have to load an old save game.
- EXIT east

#### 4.6.4. Scenery

- EXIT east

#### 4.6.5. Storage Room

- PICK UP fire extinguisher (`Fire Extinguisher`)
- USE `String` with `Fire Extinguisher` (`Contraption`)
- USE `Petrol` with `Contraption` (`Flammable Contraption`)
- USE `Flammable Contraption` with hook
- USE `Matches` with `Flammable Contraption`
