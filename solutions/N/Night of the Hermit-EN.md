# Night of the Hermit - Walkthrough

| Version | Date       | Author
|:-------:|------------|-------
|   1.0   | 13.11.2022 | Amiga Master (AmigaMaster-NG@t-online.de)

## 1. Hotel

### 1.1. Front Desk

- TALK TO receptionist
  - Ask for a room
  - Tell her you’ve only got $12
- TALK TO receptionist
  - Ask for the key (`Lockpicks`)
- PICK UP both Pamphlets from the desk (`Ride pamphlet`, `Cruise pamphlet`)
- LOOK AT `Ride pamphlet` (`Free ticket`)
- EXIT northwest

### 1.2. Left Corridor

- ENTER blue entrance

### 1.3. Entertainment Room

- LOOK AT bowl
- TALK TO goon
  - Ask about the bowl
  - Keep asking for the bowl until he asks you to get a badger sandwich
- EXIT room

### 1.4. Left Corridor

- PICK UP can from trash can (`Cat food can`)
- ENTER kitchen

#### 1.4.1. Kitchen

- TALK TO cook
- OPEN cupboard
- PICK UP Sliced bread from cupboard (`Bread`)
- PICK UP silverware from cupboard (`Knife`)
- OPEN Fridge Door
- PICK UP Lettuce (`Lettuce`)
- PICK UP Onion (`Onion`)
- PICK UP Egg (`Egg`)
- PICK UP Milk (`Milk`)
- PICK UP Cheese (`Cheese`)
- EXIT kitchen

### 1.5. Front Desk

- EXIT northeast

### 1.6. Right Corridor

- ENTER pool

### 1.7. Pool

- PICK UP jar from the table to the right (`Jar`)
- EXIT north

## 2. Beach

- EXIT east

## 3. Pier

- WALK TO Fisherman hut

### 3.1. Fisherman Hut

- PICK UP Oil (`Vegetable oil`)
- PICK UP Vinegar (`Vinegar`)
- LOOK AT Barrel
- PICK UP Badger meat (`Badger meat`)
- USE `Badger meat` with `Bread` (`Sandwich`)

## 4. Hotel

### 4.1. Entertainment Room

- USE `Sandwich` with Goon
- USE `Lettuce` with `Sandwich`

### 4.2. Right Corridor

- EXIT upstairs

### 4.3. Hallway with Doors

- USE `Lockpicks` with Barely a door
- EXIT west

### 4.4. Herman's Room

- PICK UP Gum (`Gum`)
- PICK UP Mustard from white table (`Mustard`)
- PICK UP Salt (`Salt`)
- PICK UP Pepper (`Pepper`)
- USE `Mustard` with Blender
- USE `Vegetable oil` with Blender
- USE `Pepper` with Blender
- USE `Salt` with Blender
- USE `Egg` with Blender
- USE `Vinegar` with Blender
- USE Blender
- USE `Jar` with Blender (`Mayo`)
- USE `Mayo` with `Sandwich`

### 4.5. Entertainment Room

- USE `Sandwich` with Goon
- USE `Onion` with `Sandwich` (`Badger Sandwich`)

### 4.6. Front Desk

- >Easter Egg:
  >- USE `Badger Sandwich` with badger fountain
  >- You need to recreate your badger sandwich

### 4.7. Entertainment Room

- USE `Badger Sandwich` with Goon (`Bonzo`)

### 4.8. Right Corridor

- ENTER the blue corridor

### 4.9. Blue Corridor

- LOOK AT Bowl
- TALK TO Guard dog
  - Ask about cat food
- USE `Bonzo` with `Cat food can` (`Cat food + Bonzo`)
- USE `Cat food + Bonzo` with Bowl
- PICK UP Match box (`Match`)
- PICK UP Pumpkin (`Pumpkin`)
- USE `Knife` with `Pumpkin` (`Carved pumpkin`)
- PICK UP Box o' stuff
  - You get something
  - USE you new inventory item with the Box o' Stuff until you get a Candle (`Candle`)
- USE `Match` with `Candle` (`Lit candle`, `Burnt match`)
- USE `Lit candle` with `Carved pumpkin` (`Scary pumpkin`)

### 4.10. Entertainment Room

- PUSH vase
- PICK UP Especially sharp shard (`Shard`)
- USE Light switch (behind the vase)
- USE `Scary pumpkin` with Goon
- EXIT room

### 4.11. Left Corridor

- EXIT west

### 4.12. Lounge

- PUSH note on the announcement board, so it slides to the right
- EXIT northeast

### 4.13. Left Corridor

- ENTER bar

### 4.14. Bar

- >Easter Egg:
  >- USE `Magnet` with right Window
  >- TALK TO Bartender
  >   - Ask for a game of darts (`Dart`)
  >- USE `Dart` with Bartender
  >- USE `Dart` with Dart board
- TALK TO Bartender
  - Ask for a game of darts (`Dart`)
- TALK TO Bartender
  - Tell him, your wife is calling

### 4.15. Lounge

- PULL note

### 4.16. Bar

- USE `Dart` with Dart board (`Fine wine`)
- OPEN `Fine wine` (`Engine oil`)
- TALK TO Bartender
  - Complain about the price (`Cruise ticket`)

## 5. Pier

- EXIT north

### 5.1. Booth

- USE `Cruise ticket` with Booth lady
- WALK to the deck

## 6. Ship

### 6.1. Upper Deck

- EXIT east

### 6.2. Gift Shop

- LOOK AT Portrait
- TALK TO Shopkeeper (`Hook`)
- TALK TO Shopkeeper
  - Tell him you want to become a pirate
  - Convince him (`Hook glue`)
- >Easter Egg:
  >- LOOK AT everything in the shelf
  >- TALK TO Shopkeeper
  >   - Your store stinks
  >   - Keep insisting that it stinks
- PICK UP Glass eye from shelf (`Glass eye`)
- EXIT shop

### 6.3. Upper Deck

- ENTER lower deck

### 6.4. Lower Deck

- USE `Hook` with Hammok (`Piece of thread`)
- PICK UP Rung from the Hammok (`Gold rung`)
- OPEN Dresser door
- PICK UP Uniform (`Uniform`)
- USE `Uniform` (`Herman's clothes`)

### 6.5. Upper Deck

- >Easter Egg:
  >- TALK TO Navigator
  >   - Set a course
  >   - Try different locations
  >   - SELECT "other"
  >   - ENTER "monkey island"
- PICK UP Binoculars (`Binoculars`)
- OPEN `Binoculars` (`Magnifying lens`)
- USE `Binoculars`with Navigator

### 6.6. Lower Deck

- USE `Herman's clothes`

### 6.7. Gift Shop

- >Easter Egg:
  >- TALK TO Shopkeeper
  >   - Your store stinks
  >   - Keep insisting that it stinks

### 6.8. Upper Deck

- TALK TO Navigator
  - Tell him you want to go back

## 7. Hotel

### 7.1. Lounge

- USE Sofa (`Needle`)
- PICK UP Guitar (`Guitar`)

### 7.2. Casino

### 9.1. Blue Corridor

- PICK UP Box o' Stuff

- PICK UP Match box (`Match`)

### 9.2. Pool

- USE `Gunpowder` with `Tube` (`Explosive tube`)
- USE `String` with `Explosive tube` (`Homemade TNT`)
- USE `Homemade TNT` with bulge
- ENTER hole

## 10. In Front of the Hotel

- LOOK AT Cannon (`Gunpowder`)

## 11. Hotel

- PICK UP Box o' Stuff

## 12. Pier

### 12.1. Fisherman Hut

- USE `Squid food` with Fish food (`Bucket O' badger`)
- PICK UP Fishing rod (`Fishing rod`)

## 13. Hotel

### 13.1. Blue Corridor

- PICK UP Box o' Stuff
  - Again, retry until you get a Magnet (`Magnet`)
- PICK UP Sledge hammer (`Sledge hammer`)

### 13.2. Bar

- LOOK AT Window
  - USE `Magnet` with `Fishing rod` (`Fishing magnet`)
- **ATTENTION:** SAVE YOUR GAME - you need to skip the dialog after the scene with the magnet or the game will crash!
- USE `Fishing magnet` with bush (`Weight`)

### 13.3. Kitchen

- USE `Gunpowder` with `Engine oil` (`Spiked engine oil`)
- USE `Spiked engine oil` with Cook
- OPEN `Fishing magnet` (`Fishing rod`, `Magnet`)
- USE `Magnet` with Floor
- USE `Sledge hammer` with Tile
  - **NOTE:** If this doesn't work, you need to talk to the gambler again
- PICK UP Coin (`Casino coin`)
- >Easter Egg:
  >- USE `Magnet` with Floor **4 times**
  >- USE `Sledge hammer` with Tile
  >- USE Ladder
  >- TALK TO Bernard

### 13.4. Lounge

- >Easter Egg:
  >- USE `Casino coin` with Coin slot
  >- USE Vending machine (`Piece O eight`)

### 13.5. Blue Corridor

- >Easter Egg:
  >- PICK UP Box o' Stuff
  >   - Again, retry until you get the Tube (`Wire Cutters`)

### 13.6. Casino

- USE `Casino Coin` (or `Piece O eight`) with Gambler
- PICK UP Phone dime (`Phone dime`)
- >Easter Egg:
  >- LOOK AT Screen of the Video poker machine
  >- USE `Wire Cutters` with Video poker
  >- LOOK AT Video poker
  >- LOOK AT Screen of the Video poker machine

### 13.7. Lounge

- USE `Shard` with Wallpaper under the trophy on the left wall (`Tapestry`)

### 13.8. Hallway with Doors

- USE `Lockpicks` with Barely a door
- ENTER your room

### 13.9. Herman's Room

- USE `Phone Dime` with Payphone
- USE `Tapestry` with Mirror (`Map`)
- LOOK AT `Map`

### 13.10. Front Desk

- TALK TO Receptionist
  - Ask for package (`Shovel`)
- USE `Weight` with Tray on the badger fountain

## 14. Beach

- FIND the hotspot "X marks the spot" which is between Guybrush and the sand castle
- USE `Shovel` with X marks the spot
- PICK UP Rosetta stone (`Rosetta stone`)
- LOOK AT both `Rosetta stone`
- USE `Magnifying lens` with `Scroll`
  - Decrypted text:  
    ```
    A  THREE
      HEADED MONKEY
    ```

### 14.1. Caves

#### 14.1.1. Middle of the Earth Entrance

- USE `Free ticket` with Operator

#### 14.1.2. Middle of the Earth

- >Easter Egg:
  >- USE `Shovel` with Mus **repeat with all mud piles**
  >- WALK to the lower right edge, so the elevator will hit you
  >- USE `Bell`
  >- You can TALK TO everyone
  >- WALK TO Goon to exit

- ENTER Machine room

#### 14.2.1. Machine Room

- EXIT west
