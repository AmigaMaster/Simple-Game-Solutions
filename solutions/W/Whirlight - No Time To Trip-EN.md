### 5.22. Pier

#### 5.22.1. Museum

##### 5.22.1.1. Entrance Hall

- TALK TO guard (`Note`)
- LOOK AT `Note`
  - **NOTE:**
    1. The Formula `66 (6+6) = 12` `1+2=3`
    2. The Text `Brad Kraken Xeres Dylan Bang`
    3. The marked elements and its numbers `Br`, `Kr`, `Xe`, `Ba`, `Dy`
    4. The formula is simple math `66` add the single numbers and you get `6+6 = 12`, again, add these numbers `1+2 = 3`
    5. There are similarities between the text and the element names `Brad = Br`, `Kraken = Kr`, `Xeres = Xe`, `Dylan = Dy`, `Bang = Ba`
  - If we take the element `Br`, we get the number `35` which gives us `3+5 = 8`. Continue and we get
    1. `Br` `3+5 = 8`
    2. `Kr` `3+6 = 9`
    3. `Xe` `5+4 = 9`
    4. `Ba` `5+6 = 11` and `1+1 = 2`
    5. `Dy` `6+6 = 12` and `1+2 = 3`
  - Now we take the words from the text and we get:
    1. Brad = Br   = `8`
    2. Kraken = Kr = `9`
    3. Xeres = Xe  = `9`
    4. Dylan = Dy  = `3`
    5. Bang = Ba   = `2`
