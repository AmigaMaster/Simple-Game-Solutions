# Journey Home - Walkthrough

| Version | Date       | Author
|:-------:|------------|-------------------------------------------
|   1.0   | 16.07.2026 | Amiga Master (AmigaMaster-NG@t-online.de)

## 1. Forest Clearing

- CLICK left mouse button to stand up
- PICK UP stick (on the left) (`Stick`)
- PICK UP mudslide (`Mud`)
- PICK UP damaged tree (`Tree Sap`)
- EXIT north

## 2. Forest Entrance

- LOOK AT spider
- LOOK AT sparse patch of web (in the lower right corner of the web)
- EXIT south

## 3. Forest Clearing

- USE `Tre Sap` on white boar carcass **2 times**
- WALK to the left (thy fly returns)
- PICK UP bug covered in sap (`Bug covered in Sap`)

## 4. Forest Entrance

- USE `Stick` on wrapped prey (on the right)
- PICK UP dries remains (`Skull`, `Bone`, `Cloth Fragment`)
- USE `Skull` on `Mud` (`Weighted Skull`)
- USE `Weighted Skull` on sparse patch of web
- USE `Bug covered in Sap` on spider's web
- EXIT north

## 5. Plants and Boar

- PICK UP dead rodent (`Dead Rodent`)
- USE `Dead Rodent` on ferocious plant (`Apple`)
- USE `Cloth Fragment` on `Bone` (`Bone wrapped in Cloth`)
- USE apple on tree stump
- TALK TO boar
- **QUICK:**
  - USE hanging vine (`Short hanging Vine`)
- USE `Bone wrapped in Cloth` on strange smelling bog (on the right) (`Unlit makeshift Torch`)
- EXIT north

## 6. Burning Tree

- USE `Unlit makeshift Torch` on fire (`Makeshift Torch`)
- EXIT north

## 7. Bridge

- USE `Makeshift Torch` on wolf
- PICK UP pocketed shirt fragment (`Pocketed Shirt Fragment`)
- PICK UP trouser brace (`Trouser Brace`)
- PICK UP rope (`Rope`)
- USE `Pocketed Shirt Fragment` on bloody puddle (`Blood Soaked Shirt Piece`, `Cigarette Lighter`, `Rolled Up Cigarette`)
- EXIT west

## 8. Burning Tree

- USE `Blood Soaked Shirt Piece` on fire
- PICK UP shovel (`Shovel`)
- PICK UP coffin lid piece (`Coffin Lid Piece`)
- PICK UP ornate metal cross (`Ornate Metal Cross`)
- USE `Shovel` on empty grave (Unlocks Secret 1)

## 9. Bridge

- USE `Ornate Metal Cross` on `Rope` (`Ornate Grapple`)
- USE `Ornate Grapple` on sturdy branch (in the tree on the right)
- USE ornate grapple

## 10. Lake

- PICK UP fish (`Fish`)
- USE `Makeshift Torch` on wrecked car (Unlocks Secret 2)
- USE `Trouser Brace` on sapling
- USE `Fish` on improvised catapult
- USE `Short hanging Vine` on `Shovel` (`Shovel with Vine`)
- USE `Shovel with Vine` ferry crossing (the chain)
- USE shovel with vine on chain
- USE `Coffin Lid Piece` on `Tree Sap` (`Sap Covered Coffin Piece`)
- USE `Sap Covered Coffin Piece` on large hole (in the boat)
- USE wooden boat

## 11. Gate

- USE mail box (`Medical Supplies Parcel`, `Magazine`)
- LOOK AT `Medical Supplies Parcel` (`Painkillers`, `Bandage`)
- USE `Cigarette Lighter` on metal lock
- USE `Makeshift Torch` on lock with cigarette lighter
- EXIT north

## 12. Garden

- USE door
- LOOK AT rotten basement window
- USE rotten basement window
- PICK UP metal hook (right next to the deer) (`Metal Hook`)
- USE `Metal Hook` on rotten basement window
- ENTER basement window
  - PICK UP oil can (`Oil Can`)
  - PICK UP wire wool (`Wire Wool`)
  - USE `Wire Wool` on battery (`Smouldering Wire Wool`)
  - **NOTE:** This only works if you did not die more than 3 times
  - EXIT north
- USE `Magazine` on house (Unlocks Secret 3)
- USE well lever mechanism
- USE `Oil Can` on well lever mechanism
- USE well lever mechanism
- USE `Makeshift Torch` on bucket of water (`Charred Bone`)
- USE `Charred Bone` on `Bandage` (`Charred Bone and Bandage`)
- USE `Charred Bone and Bandage` on `Metal Hook` (`Hook with Handle`)
- ENTER basement window
  - USE `Hook with Handle` on hydraulic tool (`Hydraulic Tool`, `Charred Bone and Bandage`)
  - EXIT basement
- USE `Charred Bone and Bandage` on `Oil Can` (`Unlit Makeshift Torch`)
- USE `Unlit Makeshift Torch` on `Smouldering Wire Wool` (`Makehift Torch`)
  - **NOTE:** If you do not have the `Smouldering Wire Wool`, skip to the last action
- USE `Makehift Torch` on wolf
- USE `Hydraulic Tool` on door
