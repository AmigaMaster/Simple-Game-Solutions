# A Place of Significance - Walkthrough

| Version | Date       | Author
|:-------:|------------|-------------------------------------------
|   1.0   | 01.07.2026 | Amiga Master (AmigaMaster-NG@t-online.de)

Download the free game from [Adventure Game Studio](https://www.adventuregamestudio.co.uk/play/game/2814-a-place-of-significance)

## 1. Stone Age

- USE Stone Knife (`Stone Knife`)
- **ATTENTION:** Do not use the `Stone Knife` on the altar. If you already did this, you need to restart the game as the hotspot for the altar gets removed.
- USE `Beast Carcass` on stone altar
- USE `Stone Knife` on beast carcass (`Beast heart`)
- **SAVE YOUR GAME HERE**
- USE `Beast heart` on owl ancestor (Wisdom) OR bear ancestor (Strength) OR wolf ancestor (Unity) (`Sword`)

## 2. Medieval Age

- TALK TO Nathaniel
- USE `Sword` on Nathaniel
- TALK TO Nathaniel
  - "Father Gregory would have you killed if he found out"
- USE `Sword` on Nathaniel
- USE firewood (`Firewood`)
- USE amulet (`Ornate Medallion`)
- USE Nathaniel (`Key`)
- USE `Firewood` on Nathaniel
- USE `Key` on chest (`Oil`)
- USE `Oil` on funeral pyre
- USE brazier
- USE `Ornate Medallion` on funeral pyre
- USE tunnel (`Hip Flask`)

## 3. Present

- TALK TO Cindy
- When the light goes out:
  - USE Exit (`Batteries`)
- USE `Batteries` on electric lamp
- USE duffle bag (`Chocolate Mix`, `Bottled Water`, `Metal Pod`)
- TALK TO Emma
- USE duffle bag (`Blanket`)
- USE `Blanket` on Emma
- USE duffle bag (`Bunch of Cups`)
- USE `Metal Pot` on gas burner
- USE `Bottled Water` on metal pot
- USE `Chocolate Mix` on metal pot
- **NOTE:** Do NOT use the `Hip Flask` on the metal pot
- TALK TO Cindy (`Amulet`)
- When the hot Chocolate is finished:
  - USE metal pot (`Metal Pot`)
- USE `Bunch of Cups` on folding table
- USE `Metal Pot` on big blue cups
- USE big blue cups (`Hot Chocolate`)
- USE `Hot Chocolate` on Emma
- TALK TO Emma
  - "Got everything you need?"
  - "How's the hot chocolate?"
  - "Cindy and Dale should be back soon, right?"
  - "I think the place is haunted"
  - "-End conversation-"
- **NOTE:** When the light goes out again, use the `Batteries` on electric lamp
- USE bag of chips (`Anti-Rad Syringe`, `Dog Tags`)

## 4. Future

- TALK TO Colonel Sanderson
- WAIT until the cutscene
- USE `Anti-Rad Syringe` on the character of your choice (including yourself)
