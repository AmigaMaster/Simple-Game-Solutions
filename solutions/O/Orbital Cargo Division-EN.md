## 1. Orbital Station

### 1.1. Space

- FLY right
- USE `Screwdriver` on panel
- USE airlock

### 1.2. First Floor

#### 1.2.1. Airlock

- EXIT to the elevator

#### 1.2.2. Corridor

- USE terminal
  - Activate Docking B
  - EXIT view
- ENTER station (right backdoor)

#### 1.2.3. Hallway

- EXIT right

#### 1.2.4. Elevator Corridor

- USE elevator
- EXIT right

#### 1.2.5. Robo Hub

- USE terminal
  - EXIT left

#### 1.2.6. Maintenance Shaft

- EXIT left

#### 1.2.7. Server Room

- TALK TO A.I. (the turquoise light)
- EXIT down

#### 1.2.8. Maintenance Shaft

- EXIT right

#### 1.2.9. Path to Cooling Systems

- USE vent

##### 1.2.9.1. Labyrinth

- Make your way to the exit (in the upper right corner)
  - Walk up, keep left, up, right, up and follow the path to a crossing, down and follow the path to a crossing, up and keep walking up and right, always chose the right and up path until the exit

#### 1.2.10. Path to Cooling Systems

- USE terminal
- USE the X button on the lower left (you change to Novak again)

#### 1.2.11. Elevator Corridor

- USE elevator
  - "2: Hangar"

### 1.3. Fourth Floor

#### 1.3.1. Elevator Corridor

- EXIT left

#### 1.3.2. Medical Department Hallway

- EXIT left

#### 1.3.3. Medical Department Corridor

- USE terminal
- ENTER observation room

##### 1.3.3.1. Observation Room

- TALK TO brain
- EXIT down

#### 1.3.4. Medical Department Corridor

- USE terminal
  - "I have the code. It is 1234"
- ENTER laboratory

##### 1.3.4.1. Laboratory

- TALK TO Doc (`Empty Syringe`)
- PICK UP medkit (`Medkit`)
- USE laboratory animal
- EXIT down

#### 1.3.5. Medical Department Corridor

- EXIT left

#### 1.3.6. Mortuary

- USE terminal
- USE dead body
- USE `Empty Syringe` on dead body (`Syringe with blood Sample`)

##### 1.3.6.1. Laboratory

- USE `Syringe with blood Sample` on Doc (`CPU LCV`)

#### 1.3.7. Elevator Corridor

- EXIT right

#### 1.3.8. Control Room

- USE **both** ead bodies (`(blue) Keycard`, `(green) Keycard`)
- TALK TO Zoe
- TALK TO Talli (`Note from Talli`)
- LOOK AT `Note from Talli`
- USE controls
  - READ all entries

### 1.4. Third Floor

#### 1.4.1. Elevator Corridor

- EXIT right

#### 1.4.2. First Crew Area

- USE `(green) Keycard` on (second) door lock
- ENTER (second) door

##### 1.4.2.1. Second Quarter

- USE dead body (`(red) Keycard`)
- USE `Screwdriver` on radio (`CPU XD4`)
- EXIT left

#### 1.4.3. First Crew Area

- EXIT right

#### 1.4.4. Rightmost Crew Area

- USE `(blue) Keycard` on (third) door lock

##### 1.4.4.1. Third Quarter

- USE dead body
- PICK UP key (from the table) (`Shuttle Key`)

### 1.5. First Floor

#### 1.5.1. Airlock

- USE (`(red) Keycard`) on (lowest) locked locker (`CPU VDX`)

### 1.6. Second Floor

#### 1.6.1. Elevator Corridor

- EXIT right

#### 1.6.2. Right Hangar

- USE `Shuttle Key` on shuttle
- USE shuttle entry
  - "Satellite"

## 2. Satellite

- FLY right
- USE `Screwdriver` on maintenance hatch
- USE maintenance hatch
  - PUT the CPU's in the following positions. The CPU's are placed in the following order: XD4, VXD, LVC
    - E2: XD4
    - D1: VXD
    - B1: LVC
  - EXIT
- USE shuttle
  - "Freighter"

## 3. Freighter

- ENTER hole in the freighter

### 3.1. Inside Freighter

- USE box (the one on the right side)
- USE `Screwdriver` on bars
- USE bars

### 3.2. Shaft

- EXIT south

### 3.3. Elevator

- USE open box (`Battery`)
- EXIT right

### 3.4. Hallway

- USE junk (in the bottom screen) (`Decrypter`)
- USE `Decrypter` on `Battery` (``)
- EXIT to the shuttle
  - "Satellite"

## 4. Satellite

- USE maintenance hatch
  - D4: XD4
  - B3: VXD
  - D2: LVC
  - EXIT
- USE shuttle
  - "Orbital Station"
