## 1. Second Floor

### 1.1. Apartment I

#### 1.1.1. Dungeon

- PICK UP bone (`Femur`)
- PICK UP bowl (`Bowl with water`)
- USE `Femur` on box of sulfuric powder (in the shelf on the right)
- PICK UP box of sulfuric powder (`Sulfuric powder`)
- USE `Sulfuric powder` on lock
- USE `Bowl with water` on lock with sulfuric powder (`Empty bowl`)
- USE door
- EXIT through door

#### 1.1.2. Main Room

- OPEN refrigerator
- PICK UP butter (`Butter`)
- USE `Butter` on `Empty bowl` (`Bowl with cold butter`)
- ENTER bathroom

#### 1.1.3. Bathroom

- USE `Bowl with cold butter` on cold radiator
- USE cold radiator
- PICK UP bowl (`Bowl with melted butter`)

#### 1.1.4. Main Room

- USE `Bowl with melted butter` on (right) door
- USE (right) door

### 1.2. Hallway

- EXIT downstairs (on the right side)

## 12. Third Floor

### 12.1. Hallway

- USE `Sacred Robe with Beard`
- USE door with symbols

### 12.2. Apartment I

#### 12.2.1. Party

- TALK TO withered Sister
- TALK TO wise Brother
- TALK TO thick-tongued Brother
- TALK TO illustrious Brother organist
- TALK TO blithe Sister
- TALK TO brother Solicitous
- ENTER library

#### 12.2.2. Library

- TALK TO glorious supreme Brother
- LOOK AT crimson bible

#### 12.2.3. Party

- TALK TO brother Solicitous
- TALK TO illustrious Brother organist
- TALK TO blithe Sister
- TALK TO withered Sister
  - "I still think, something's..."
  - "Are you drinking..."
  - "I'll call the other brothers..." (`Alcohol`)
- USE `Femur` on blender (at the bar)
- USE blender (`Powdered bone`)

#### 12.2.4. Library

- TALK TO glorious supreme Brother
  - "About the ritual..."
  - "Ready to go up!"
- USE `Powdered bone` on glorious supreme Brother
- USE `Alcohol` on glorious supreme Brother

#### 12.2.5. Party

- PICK UP bowl of Doritos (`Doritos`)
- TALK TO thick-tongued Brother

#### 12.2.6. Library

- USE `Doritos` on glorious supreme Brother

#### 12.2.7. Attic

- USE `Doritos` on plate
- USE `Alcohol` on fleshbound offering
- USE `Powdered bone` on symbol (above the candles)
- USE coffin
  - CHOOSE as you like (the correct ones would be "3 times" & "Per noctem...")
- PICK UP candle (from the table) (`Candle`)
- USE `Candle` on alcohol-soaked offering
  - CHOOSE as you like (the correct one would be "Ambulor...")
