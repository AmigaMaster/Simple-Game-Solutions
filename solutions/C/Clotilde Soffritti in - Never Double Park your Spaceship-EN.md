# Clotilde Soffritti in: Never Double Park your Spaceship - Walkthrough

| Version | Date       | Author                                    |

Download the free game at [Itch.io](https://lorenzob.itch.io/clotilde2)

## 1. Meteorite

### 1.1. Bonfire

- USE wonky bookcase
  - PICK UP book of cooking (`Cookbook`)
  - PICK UP book on signals (`Book on signals`)
- USE fridge
  - PICK UP wine bottle (`Bottle of wine`)
  - PICK UP Cough syrup (`Frozen cough syrup`)
  - USE Control knob to switch off the fridge
  - USE `Multi-tool` with fan (`Fan`)
- USE `Multi-tool` with `Fan` (`Small grid`)
- USE Toolbox (`Box of nails`)
- TALK TO hermit
- Exit west

### 1.2. Crash Site

- PICK UP weeds (`Weed`)
- USE `Multi-tool` with panel
- PICK UP metal panel (`Metal panel`)
- USE `Metal panel` with sticky puddle (`Sticky panel`)
- USE `Sticky panel` with `Box of nails` (`Metal panels with nails`)
- USE `Metal panels with nails` with hermit
- LOOK AT `Cookbook`
  - **NOTE:** The recipe of Scaloppo Punch:
    - Cough Syrup
    - Vinegar (apple or grape)
    - Aromatic herbs
- USE `Frozen cough syrup` with bonfire (`Cough syrup`)
- USE `Weed` with `Cough syrup`
- USE `Bottle of wine` with `Cough syrup`
- LOOK AT `Book on signals`
  - You need to create a signal
  - How many: Single person (I)
  - Type: stuck on asteroid (Delta)
  - Need help with: need a passage (BACON)
- USE radio
  - USE `Cough syrup` with fuel funnel - **NOTE:** You need to have mixed the Scaloppo punch for this to work
  - USE `Small grid` with antenna
  - USE old radio
    - Select number "I"
    - Select the "Delta" sign at the knob
    - Select the "Bacon"
    - Select the interstellar range (the plaque with the planet)

## 2. Byroldo

### 2.1. Garage

- TALK TO depressed-looking robot
- USE lift
- Exit east

### 2.2. Main Street

- TALK TO cook
  - Order a spleen sandwich (`Spleen sandwich`)
  - Order a stomach sandwich (`Cow stomach sandwich`)
- ENTER office

#### 2.2.1. Office

- TALK TO receptionist
- USE vending machine
  - PICK UP lyophilized soup (`Flavorless food`)
  - PICK UP cold coffee (`Plastic cup`)
- Try to enter the door to the left
- USE computer **6 times** (until you repeat your comments)

### 2.3. Main Street

- TALK TO cook
  - "Can you prepare something special?"
- GIVE `Cookbook` to cook
- TALK TO cook
  - "Can you make me ant soup?"
- LOOK AT smelly smoke
- USE `Fan` with smelly smoke
- ENTER office

#### 2.3.1. Office

- PICK UP key (`Key`)
- Exit west

#### 2.3.2. Hallway

- TALK TO robot
- USE `Key` with toilet door
- ENTER toilet

#### 2.3.3. Toilet

- USE hand dryer
- USE `Plastic cup` with hand dryer (`Melted plastic cup`)
- USE `Melted plastic cup` with sink
- USE sink

#### 2.3.4. Hallway

- USE `Key` with toilet door
- ENTER office

#### 2.3.5. Office

- USE computer
  - USE knob to change to garage number 8
  - USE print button
- PICK UP card (`Keycard for the garage`)

### 2.4. Garage

- USE `Keycard for the garage` with lift
