## 1. Space Ship

### 1.1. Main Room

- USE Door
- PICK UP Golf balls (`Golf balls`)
- PICK UP Box (`Box`)
- PICK UP Helmet (`Helmet`)
- USE `Multi-tool` with `Box` (`Book`)
- LOOK AT `Book` (`Photograph`)
  - Note the colors and descriptions
  - Violet, red, blue, mussels, sulphur, clouds
- LOOK AT `Photograph`
- USE Broken door
- USE `Multi-tool` with Panel
- PICK UP Battery (`Battery`)
- USE Food producer
  - Martian Slug Dripping (`Food?`)
  - Caeruleus Soda (`Drink`)
- USE `Drink` on `Helmet` (`Painted helmet`)
- USE `Golf balls` with `Painted helmet`
- USE `Battery` with Sink
- USE `Food?` with Battery
- USE `Golf balls` on Battery (`Sticky golf balls`)
- USE `Sticky golf balls` with `Painted helmet` (`Blue Helmet with golf balls`)
- USE `Blue Helmet with golf balls` with camera
- ENTER Exit

### 1.2. Bridge

- USE Ship's computer
  - Enter the color code you get form the book
  - Violet, red, blue, mussels (black), sulphur (yellow), clouds (white)
