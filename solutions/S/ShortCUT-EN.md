## 1. Walkthrough

- PICK UP mirror (`Mirror`)
- USE `Mirror` on button (of the middle window)
- USE chest **2 times** (`Coin`)
- USE `Coin` on coin slot (of the vending machine)
- USE button (of the vending machine)
- USE slot (at the bottom of the vending machine)
- USE button (of the machine in the bottom left corner)
- PICK UP item in hole (`Pole`)
- USE button (below the right window)
- PICK UP hook (on top of the weight) (`Hook`)
- USE `Hook` on `Pole` (`Hook-on-Pole`)
- USE `Hook-on-Pole` on slot (of the vending machine) (`Hard Clay`)
- USE `Hard Clay` on hole (of the machine at the bottom left)
- USE button (of the machine at the bottom left)
- PICK UP item in hole (`Soft Clay`)
- USE `Soft Clay` on key hole (of the door)
- PICK UP clay (`Soft Key`)
- USE `Soft Key` on hole
- USE button (of the machine at the bottom left)
- PICK UP item in hole (`Hard Key`)
- USE `Hard Key` on key hole
