# Steeplejack - Walkthrough

| Version | Datum      | Autor                                     |

|   1.0   | 31.12.2025 | Amiga Master (AmigaMaster-NG@t-online.de) |

## 1. Top of Chimney

- PICK UP nail (`Nail`)
- USE toolbox
- USE `Nail` on toolbox (`Tools`)
- USE `Tools` on brickwork
- USE lunch box (`Scotch egg`, `Tabasco`, `Peanuts`)
- LOOK AT `Pipe` (`Stem`)
- USE `Tabasco` on `Peanuts` (`Spicy peanuts`)
- USE `Spicy peanuts` on `Stem` (`Blowpipe`)
- USE `Blowpipe` on massive pigeon
- USE look down (on the left egde)
- USE `Scotch egg` on void

## 2. Ground

- USE rear of landrover
  - PICK UP rope (`Very long rope`)
  - USE toolbox (`Bradawl`)
  - EXIT view
- USE front of land rover
- USE `Penknife` on `Headphones` (`Wire`)
- USE `Wire` on front of land rover
- USE front of land rover
  - PICK UP box (`Gloves`)
  - EXIT view
- USE `Bradawl` on canister
- USE `Gloves` on canister (`Inflated gloves`)
- USE `Inflated gloves` on `Very long rope`
