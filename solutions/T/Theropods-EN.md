# Theropods - Walkthrough

| Version | Date       | Author                                    |
|:-------:|------------|-------------------------------------------|
|   1.0   | 17.09.2026 | Amiga Master (AmigaMaster-NG@t-online.de) |

## 1. Jungle Path

- Keep walking east

## 2. Cave

- EXIT east

## 3. Cave Entrance

- CLIMB DOWN the ladder
- >ACHIEVEMENT: Popular (1/7)
  >- TALK TO woman on the left (at the baskets)
- EXIT east

## 4. Path to the Village

- >ACHIEVEMENT: Popular (2/7)
  >- TALK TO old woman
- PICK UP **both** bowl pieces (`Bowl Piece`, `Bowl Piece`)
- USE `Bowl Piece` on sap (at the tree) (`Bowl Piece with Sap`)
- USE `Bowl Piece with Sap` on `Bowl Piece` (`Bowl`)
- USE `Bowl` on water (`Bowl with Water`)
- >ACHIEVEMENT: Woof & Popular (3/7)
  >- TALK TO man eating an apple **3 times**
- EXIT north

## 5. Village

- >ACHIEVEMENT: Popular (4-7/7)
  >- TALK TO woman at the pottery
  >- TALK TO man at the path to the east
  >- TALK TO the woman braiding the hair of the man
  >- TALK TO old man with the cane
- WALK west
  - **NOTE:** You need to find the three kids
- USE kid in the center right of the stone behind the leaves (First kid)
- EXIT south

## 6. Path to the Village

- USE the left basket (Second kid)
- USE stalk in the small river (Third kid)

## 7. Village

- WALK west (with all three kids)
- EXIT northwest

### 7.1. Cave

- TALK TO man on the stone throne
- FOLLOW him to the upper level
- >ACHIEVEMENT: Legacy
  >- USE man (father) on spear (of the statue) (`Spear`)

## 8. Jungle Path

- USE `Spear` on dinosaur
- EXIT east

## 9. Southeastern Jungle Path

- PICK UP stake (On the ground under the man) (`Stake`)
- USE `Spear` on man
- USE man on left exit
- EXIT west (follow him)

## 10. Jungle Path

- USE man on red fruit (at the top)
- PICK UP fruit (`Fruit`)
- USE butterfly
- USE `Spear` on vine
- PICK UP vine (`Vine`)
- EXIT north

## 11. Jungle Crossing

- EXIT north

## 12. Cliff

- USE `Vine` on the left big tree branch
- USE `Stake` on vine
- USE `Fruit` on vine
- EXIT south, southeast, west, north

## 13. Jungle Crossing

- **QUICK:**
  - EXIT up the tree

### 13.1. Tree Top

- USE branch **3 times**

## 14. Jungle Crossing

- EXIT southeast, west, north
- USE man on tree on the right side
- EXIT southeast, west, north
- EXIT north

## 15. Cliff

- >ACHIEVEMENT: Hunter
  >- USE `Spear` on dinosaur

## 16. Cave

- PICK UP bone (`Bone`)
- EXIT east

## 17. Cave Entrance

- USE `Bone` on leave (`Leave`)
- USE bushes (`Berries`)
- USE `Berries` on `Leave` (`Leave with Red Berries`)
- USE `Leave with Red Berries` on cave entrance
- >ACHIEVEMENT: Slide
  >- USE `Bone` on cave entrance
- CLIMB down and EXIT east

## 18. Path to the Village

- PICK UP red berries (on the left) (`Berries`)
- USE `Berries` on wind chime
- **QUICK:**
  - USE `Berries` on kid in the tree
- USE kid on man
- CRAWL east
- PICK UP necklace (a small, sometimes blinking white ting on the ground) (`Necklace`)
- USE `Necklace` on bucket (next to the man) (`Torch`)
- USE `Torch` on campfire (`Lit Torch`)
- USE `Lit Torch` on banner (at the left)
- >ACHIEVEMENT: Fired
  >- USE banner
- USE kid

## 19. Village

- WALK west
- PICK UP spear (on the ground in front of yourself)
- USE `Spear` on man (`Stick`)
- PICK UP spearhead from the ground (`Spearhead`)
- USE `Stick` on man
- **QUICK:**
  - USE `Spearhead` on man
- PICK UP cloth (from the ground in front of yourself) (`Cloth`)
- USE `Cloth` on the brown/orange thing to your left bottom (`Pebbles`)
- USE `Stick` on man
- **QUICK:**
  - >ACHIEVEMENT: Snap
    >- USE `Pebbles` on man

## 20. Crash Site

- PICK UP staff (below the ramp) (`Staff`)
- ENTER capsule

### 20.1. Capsule

- USE panel (on the right side)
  - PRESS buttons from top to bottom
- USE `Staff` on fire extinguisher (`Fire Extinguisher`)
- EXIT east

## 21. Crash Site

- When the hose is facing away from the yellow power crystal:
  - USE `Staff` on yellow power crystal
- PICK UP power crystal (`Power Crystal`)
- PICK UP yellow hose (`Hose`)
- USE `Hose` on `Fire Extinguisher` (`Fire Extinguisher with Hose`)
- USE `Fire Extinguisher with Hose` on **all three** fires
- PICK UP blue thing from the ground (`Robot Head`)
- WALK east to the bug, then west until the bug is on the hatch
- USE `Power Crystal` on capsule
- USE red button
- PICK UP bug (`Dead Bug`)
- USE `Dead Bug` on venus flytrap
- PICK UP robot piece (`Robot Piece`)
- WALK east to the dinosaur, then enter the capsule

### 21.1. Capsule

- PICK UP bag from the ground (`Snack Bag`)

## 22. Crash Site

- USE `Snack Bag` on dinosaurs **3 times**
- USE `Staff` on yellow power crystal
- PICK UP power crystal (`Power Crystal`)
- PICK UP robot part (inside the dead dinosaur) (`Robot Hands`)
- USE `Robot Hands` on `Robot Piece` (`Incomplete Robot`)
- USE `Robot Head` on `Incomplete Robot` (`Inactive Robot`)
- >ACHIEVEMENT: Beepboop
  >- USE `Power Crystal` on `Inactive Robot` (`Robot`)
- USE `Staff` on fish in the river
- USE `Robot` on puddle in front of the river
- USE `Staff` on fish in the river
- PICK UP fish (`Fish`)
- USE `Fish` on bird
- PICK UP rope (on the ground in front of the bird) (`Rope`)
- USE `Rope` on woman in the river
- PICK UP woman
- PICK UP stick (beside the water) (`Stick`)
- USE `Stick` on fuel puddle (at the capsule) (`Petrol-soaked Stick`)
- USE `Petrol-soaked Stick` on `Flame` (`Lit Torch`)
- >ACHIEVEMENT: Guts
  >- USE bird

## 23. Cave Entrance

- PICK UP skeleton (above the cave)
- PICK UP bone (`Bone`)
- USE `Bone` on horn (below the tree stump) (`Horn`)
- CLIMB onto the cave
  - USE branch (under the big rock) **3 times**
  - CLIMB down
- USE `Horn` on dinosaur
- USE skeleton **3 times**
- CLIMB down the skeleton
- PICK UP spear
- PICK UP spear **again** (`Spear`)
- USE `Robot` on ledge (above)
- PICK UP skull (`Skull`)
- WALK west
- USE `Skull` on small opening
- PICK UP grass (on the right) (`Grass`)
- USE `Grass` on rock (the small round plate-like rock in the middle)
- USE `Flame` on grass
- PICK UP scorpions (`Scorpion`, `Scorpion`, `Scorpion`)
- USE **all three** `Scorpion` on snake
- USE `Spear` on snake (`Snake Skin`)
- USE `Snake Skin` on `Spear` (`Spear with Snake Skin`)
- >ACHIEVEMENT: Snake Charmer
  >- USE `Spear with Snake Skin` on cactus

## 24. Nest

- USE lizard
- PICK UP skull (`Skull`)
- USE `Skull` on grass on the right
- PICK UP bush (on the left side) (`Thorns`)
- Make sure, you are on the left side
- SWITCH TO alien (TAB)

> Alien

- USE lizard

> Amazon

- PICK UP skull (`Skull with Lizard`)
- USE `Thorns` on `Skull with Lizard` (`Poison`)
- USE `Spear` on `Skull with Lizard`
- **QUICK:**

> Alien

- PICK UP bone tube (`Bone Tube`)
- USE `Bone Tube` on Amazon

> Amazon

- PICK UP bone tube (`Bone Tube`)
- USE `Bone Tube` on `Poison` (`Poisoned Bone Tube`)
- USE `Poisoned Bone Tube` on dinosaur (`Thorned Bone Tube`)
- CLIMB over the stones
- USE alien

> Alien

- PICK UP egg shell (from the dinosaur tail) (`Eggshell`)
- USE `Eggshell` on `Robot` (`Shell Robot`)
- USE `Shell Robot` on nest
- EXIT down the cliff (the other dinosaur will arrive)
- **QUICK:**

> Amazon

- USE `Thorned Bone Tube` on dinosaur

> Alien

- PICK UP robot (`Meat`, `Robot`)
- >ACHIEVEMENT: Yum
  >- USE `Meat` on nest **3 times**

## 25. Free Fall

- SELECT any of the two characters

## 26. Alien

### 26.1. Underwater

- PICK UP glowing fish (`Glowing Fish`)
- PICK UP pink coral (`Coral`)
- EXIT down

### 26.2. Cave Entrance

- USE `Glowing Fish` on bug (`Bug`)
- EXIT east

### 26.3. Inside Cave

- EXIT up

### 26.4. Dark Underwater Passage

- USE `Coral` on clam
- PICK UP clam (`Clam`)
- USE `Clam` on jellyfish (`Clam with Jellyfish`)
- WALK east into the light

### 26.5. Inside Cave

- USE `Clam with Jellyfish` on jellyfish (`Clam with 2 Jellyfishes`)

### 26.6. Cave Entrance

- USE `Clam with 2 Jellyfishes` on jellyfish (`Clam with 3 Jellyfishes`)

### 26.7. Dark Underwater Passage

- USE `Clam with 3 Jellyfishes` on background (to call the big fish)

### 26.8. Cave Entrance

- PICK UP stone (on the ground near the entrance on the left) (`Stalactite`)

### 26.9. Inside Cave

- USE `Stalactite` on hole
- USE `Bug` on cold seep

### 26.10. Dark Underwater Passage

- USE `Clam with 3 Jellyfishes` on background (the jellyfish moves to the left)
  - **REPEAT** these steps
- PICK UP bug (`Bug`)

### 26.11. Cave Entrance

- USE `Bug` on right cold seep
- CLIMB up

### 26.12. Underwater

- USE `Clam with 3 Jellyfishes` on background
  - **REPEAT** these steps, always picking up the bug from the cold seeps until the big jellyfish is near the entrance

### 26.13. Cave Entrance

- USE `Bug` on left cold seep

### 26.14. Underwater

- >ACHIEVEMENT: Zap
  >- USE `Clam with 3 Jellyfishes` on background (the fish will get shocked by the jellyfish)

### 26.15. Dark Underwater Passage

- EXIT northeast

## 27. Amazon

### 27.1. Beach

- USE palm
- PICK up coconut (`Coconut`)
- USE `Spear` on crab
- **QUICK:**
  - USE `Coconut` on crab
- PICK UP coconut (`Coconut`)
- PICK UP spear (`Spear`)
- PICK UP crab (`Crab`, `Shell`)
- USE `Shell` on sand (`Shell with Sand`)
- USE `Shell with Sand` on robot
- USE `Spear` on robot (`Power Crystal`)
- USE `Power Crystal` on robot
- EXIT east

### 27.2. Pond

- EXIT northwest

### 27.3. Northwestern Jungle

- PICK UP plant (to the left) (`Leaves`)
- EXIT south

### 27.4. Pond

- USE `Leaves` on log
- USE robot on leaves

### 27.5. Beach

- USE palm
- PICK UP palm leaf (`Palm Leaf`)

### 27.6. Pond

- USE `Palm Leaf` on fire
- USE `Spear` on log
- USE log
- USE `Crab` on log
- USE `Spear` on log
- >ACHIEVEMENT: Fishy
  >- USE `Spear` on vines
- EXIT northeast

### 27.7. Northeastern Jungle

- USE `Coconut` on brown spot on the ground

### 27.8. Northwestern Jungle

- USE robot on dinosaurs

### 27.9. Northeastern Jungle

- PICK UP smashed coconut (`Smashed Coconut`)
- USE `Smashed Coconut` on bamboo

### 27.10. Northwestern Jungle

- USE robot
- >ACHIEVEMENT: Bamboozled
  >- EXIT east

## 28. River

- USE `Spear` on vines (`Vines`)
- EXIT west

## 29. T-Rex

- USE `Vines` on rock in the river (`Vine`)
- EXIT east

## 30. River

- USE `Vine` on `Spear` (`Spear with Vine`)
- USE `Spear with Vine` on tree on the right side
- USE tree
- USE carcass **3 times**
- CLIMB back to the west
- USE `Spear with Vine` on the floating log as soon as they appear in the right corner **3 times**

## 31. T-Rex

- >ACHIEVEMENT: Stab
  >- USE `Spear with Vine` on T-Rex

## 32. Tree

- When the T-Rex is stunned:
  - PICK UP spear (`Spear`)
- USE `Spear` on horn (`Horn`)
- USE `Horn` on vines on T-Rex
- >ACHIEVEMENT: A Long Drop
  >- USE `Spear` on vines below **3 times**
- CHOOSE you character to continue with

## 33. Alien

- USE man **3 times**
- PICK UP tomatoes (`Tomatoes`)
- USE `Tomatoes` on man (you switch sides)
- USE post **3 times**
- PICK UP skull (`Skull`)
- USE `Skull` on man
- PICK UP banner (`Banner`)
- USE `Banner` on yourself
- USE `Tomatoes` on man
- USE `Skull` on man
- >ACHIEVEMENT: One-Punch Spaceman
  >- USE banner

## 34. Amazon

- USE woman on bone (above her) **3 times**
- USE woman on purple cloth
- USE kid on bone on man
- USE kid on cloth on rocks
- USE kid on cloth on man
- USE kid on rocks on man
- USE man on bone on cloth
- USE kid on rocks on torch
- USE man on blaze on green rope
- USE woman on vine
- USE kid on rocks on enemy
- USE man on vine **2 times**
- >ACHIEVEMENT: Escape
  >- USE vine

## 35. Lower Area

- PICK UP knives (`Knife`)
- USE `Knife` on (upper) enemy (you can scroll up the picture)
- USE `Knife` on left wooden pole
- USE `Spear` on right wooden pole
- USE `Spear` on crystal (hovering over the Amazon) (`Crystal`)
- USE `Crystal` on `Knife`

## 36. Upper Area

- WALK west
- USE `Spear` on knife (`Knife`)
- USE `Knife` on enemy
- USE knife **3 times** (`Knife`)
- USE `Knife` on enemy
- USE `Spear` on enemy
- USE enemy
- USE Amazon
- >ACHIEVEMENT: Big Bang
  >- USE crystal **4 times**

## 37. Cave

- EXIT east and walk into the village

## 38. Village

- >ACHIEVEMENT: Tribe
  >- EXIT east
