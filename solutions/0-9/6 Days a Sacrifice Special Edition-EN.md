|:-------:|------------|-------------------------------------------

Download the free game from [archive.org](https://archive.org/details/chzomythos)

## 1. Optimology Building

- PICK UP pamphlet (from the desk)

## 2. Day One

### 2.1. Laboratory

- TALK TO guard
  - "Urrgh..."
- USE guard (`Paper`)
- USE `Paper` on Samantha
- TALK TO Samantha
  - "Point to the console."
  - "Point to the door in the north wall."
- USE (right) door

### 2.2. Main Hallway

- PICK UP spectacles (`Lens`)
- EXIT right

### 2.3. Steel Door Hallway

- EXIT left

### 2.4. Main Hallway

- USE (first) door (`Guns`)
- USE `Guns` on Samantha

## 3. Day 2

### 3.1. Main Hallway

#### 3.1.1. Sleeping Room

- USE (right) door
- USE book
- USE post-it note (on the locker)
- USE ((left)) door

### 3.2. Main Hallway

- WALK right

#### 3.2.1. Storage Room

- USE ((left)) door

### 3.3. Main Hallway

- WALK to the (left) until the guard walk towards you
- **QUICK:**
  - USE door (to the storage room)

#### 3.3.1. Laboratory

- EXAMINE `Cellphone`
  - "Samantha Harty"
    - "I got the guard away from the door."
- USE (right) door

### 3.4. Main Hallway

- TALK TO Samantha (to the (left))
- USE note
- USE ((left)) door

### 3.5. Main Hallway

- USE (first) door

#### 3.5.1. Bedroom

- USE locker
  - SELECT `OPEN`
  - CLICK on the X
- USE locker
- PICK UP keycard (`Keycard`)
- USE ((left)) door

### 3.6. Main Hallway

- USE (third) door

#### 3.6.1. Office

- USE computer
  - "Release level 1 security"
- USE door

### 3.7. Main Hallway

- USE (sixth) door (or the second door from the right)

#### 3.7.1. Security Room

- USE touchscreen
  - "Change Camera"
  - "Camera 4"
- USE touchscreen
  - "Review input"
- USE `Lens` on monitor
  - **NOTE:** `7759`
- USE ((left)) door

### 3.8. Main Hallway

- EXIT right

### 3.9. Steel Door Hallway

- USE `Keycard` on slot (at the (left) side of the door)
- USE keypad (at the right side of the door)
  - ENTER the code from camera 4 `7759`
- EXAMINE `Cellphone`
  - "Janine Orzechowski"
    - "We need your help to USE Hub."
- USE (right) door

### 3.10. Main Hallway

#### 3.10.1. Laboratory

- USE (right) door
