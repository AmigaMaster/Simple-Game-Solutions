## 5. Residence Deck

### 5.1. Your Quarter

- PICK UP wrench set (form the table) (`Wrenches`)
- USE door

### 5.2. Corridor

- USE elevator (it does not work)
- USE (right) door

### 5.3. Canteen

- TALK TO Adam
- USE dispenser
  - "Continental" (`Breakfast`)
- USE `Breakfast` on counter (`Butter`)
- USE `Wrenches` on hatch
- USE shaft

#### 5.3.1. Maintenance Shaft

- EXIT west

### 5.4. Top of Elevator

- USE butter on object
- PICK UP object (`Machete`)
- USE shaft
- EXIT east

### 5.5. Canteen

- USE `Machete` on Adam

## 18. Engine Deck

### 18.1. Brig

- PICK UP towel rail (`Tower Rail`)
- **ATTENTION:** SAVE YOUR GAME HERE
- TALK TO Angela
  - "Angela, while I'm here..."
  - "I think there is someone..."
- **QUICK:**
  - PICK UP stun gun (`Stun Gun`)
  - USE `Stun Gun` on Barry
- USE door

### 18.2. Reactor Core

- WALK to the shadow behind the big pipe
- WAIT until Barry arrives and looks at the reactor core
- USE `Towel Rail` on Barry
